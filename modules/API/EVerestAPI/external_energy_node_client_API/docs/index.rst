.. *******************************************
.. external_energy_node_client_API
.. *******************************************

The external_energy_node_client_API module is always used in conjunction with the **external_energy_node_API**
module, running in a separate EVerest process and connected to it over external MQTT.
See the :ref:`documentation <everest_modules_handwritten_external_energy_node_API>` of the latter for a detailed
explanation of the architecture, message flow, and configuration shared by the two modules.
