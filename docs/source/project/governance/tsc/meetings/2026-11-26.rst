Notes

Decisions:
- Vote: remove JOET, on their own wish. Result: all in favor, accepted
- Vote postponed: make contributing to federated testing (Himalayas) mandatory on the path to becoming a TSC member. Good discussion, all in principle positive

Other:
- 2026.10.0 released on 26 November: 53 contributors (27 first-time), 8 breaking changes and 14 deprecations, see the release notes: https://github.com/EVerest/EVerest/releases/tag/2026.10.0
- 2026.02.2 patch release published on 5 November with security fixes; security fixes now target 2026.10
- Release scope: one C++ ISO 15118 stack (DIN 70121, -2, -20), OCPPmulti (1.6, 2.0.1, 2.1), AC DER / V2X, EvseSlac, MCS, manager overhaul, security hardening
- Compliance: tested against ISO 15118-4, -5 and -21 test cases and with OCTT for OCPP 1.6 and 2.0.1 (2.1 partially)
- AFIR: 11 of 12 charger-side obligations ready in EVerest, the 12th (opt-out of automatic authentication) is an integrator HMI choice; covers the 1 Jan 2027 ISO 15118-20 mandate; scorecard: https://www.pionix.com/everest-afir
- Himalayas: 1,456 tests (each counted once), 96% passed; Pionix and Kempower report on main, Zaptec on 2026.10 with a first HIL setup; status at https://everest.github.io/Himalayas/
