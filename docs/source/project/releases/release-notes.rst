#############
Release Notes
#############

The release notes of every EVerest release are published on the
`GitHub releases page <https://github.com/EVerest/EVerest/releases>`_. Each set
of notes lists the highlights, the changes that need action when upgrading,
the deprecations and experimental components of that release, new features,
notable fixes, security advisories and the contributors.

Before upgrading to a new stable release line, read the release notes of the
target release and the upgrade guide for it. Upgrades within a stable line
(``yyyy.mm.x``) contain no breaking changes, see
:ref:`project-release-and-versioning`.
